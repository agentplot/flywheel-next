## What the live run showed and how it was met

- The work order names the binary by full path; a pane's shell has no
  `flywheel` on its path.
- `flywheel init` defaults the address to `http://<hostname>.local`; a host
  refuses a localhost address.
- Claude Code asks whether the folder is trusted before it takes a prompt.
  `Herdr::clear_the_way` answers it from what the pane shows and waits for
  the prompt line; the first prompt follows.

## Left as the model has it, worth a look

- A session's pane outlives its exit: `end_session` runs only from `ended`,
  which the owner's explicit end reaches (`session.yaml`), so a done agent's
  pane stays in Herdr until closed by hand. Whether a passed stage should end
  it is a model question.
- `write_acceptance` on the host workspace writes an empty file under
  `flywheel/acceptance/`; the recorded binding's body is kept. What the
  acceptance should carry is a model question.
- A tracked repository adopted by init gains the template commit
  (`flywheel/.keep`).
- The `unit…` control is offered on every capture, moved or not.
- `place_key` gives a session's place as the object id and the place's own
  region as `<object>#own`; `place_dir_of` in host.rs tries both. The model
  should say which.
- A place's `devenv.nix` is not activated before the session starts
  (`host.yaml` says it is); the agent runs in the operator's shell.
