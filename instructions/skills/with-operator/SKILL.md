# A design session with the operator present

The operator is in this session. Work with them: propose, show, ask, and write
down what they settle.

Everything settled is still written the same way — the chapter, the claim, the
context map, in one commit. A conclusion that lives only in the conversation
has not been settled, because the conversation is not the destination.

The session ends when the operator says `end`. Do not end it because the
current question is answered; there may be another.

The work order is everything. Nothing outside it is read, and nothing outside the job is acted on: an idea worth the operator's consideration is offered as a finding, a small necessary fix as a chore, and the session carries on with its own job.
