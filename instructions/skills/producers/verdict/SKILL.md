# Producing a verdict

Read the claim, read its scenarios, then look for evidence in the repository
that each scenario holds. Judge from what is there, not from what the work
said it did.

Record the inputs. A verdict whose inputs are not named cannot be reused when
the claim's version moves, so it is worth nothing later.

Not applicable is a judgment: say why the claim does not reach this
repository.

Done when a reader could disagree with the judgment specifically, and
`flywheel/schemas/verdict.md` holds.
