# Producing an intent proposal

State the subject as what is unsettled, in one line. Attach the signals it
rests on with their weight, and propose the elaborations that would settle it,
each of a type the registry knows.

Check the open intents first: a subject already open takes an attachment, not
a new proposal.

Done when the operator could say yes or no from the proposal alone, and
`flywheel/schemas/intent-proposal.md` holds.
