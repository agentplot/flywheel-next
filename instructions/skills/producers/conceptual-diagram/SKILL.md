# Producing a conceptual diagram

Draw only what a person in the domain would name. Use the book's word for
every shape, spelled the book's way.

Take the palette, the shapes and the flow direction from
`flywheel/schemas/diagram-conceptual.md`; nothing here is a matter of taste,
because the point is that every diagram in the book looks like one system.

Done when a reader who has not read the chapter can name the parts from the
picture alone.
