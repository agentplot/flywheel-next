# Producing a planning proposal

Read the backlog, the as-built and the open bolts before writing a line. The
proposal argues for a batch, so the case comes first and the units follow.

Size every unit in slot-days against the actuals for that type in this
repository, not against a feeling. Where there are no actuals, say so.

Split any unit that needs "and" to describe. Cite the standing claims each
unit serves, and say plainly where none fits.

Done when the operator could approve or annotate it without opening anything
else, and `flywheel/schemas/proposal.md` holds.
