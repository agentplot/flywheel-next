# Producing a book chapter

Write for the reader who arrives knowing nothing and needs to act. Open with
the question, answer it, then earn the answer.

Find the chapter this belongs in before writing a new one. A destination
described twice is a destination described wrong.

Include each claim by anchor at the point the prose has made it inevitable,
and check that the sentence before the anchor and the claim's text say the
same thing in different registers.

Done when the chapter reads as a description of a system that exists, and the
schema `flywheel/schemas/book-chapter.md` holds.
