# Producing a claim

Say what is true at the destination in one sentence, then write the scenario
that would catch it not being true.

Amend before adding. Search the standing specifications for a claim about this
subject; if one exists, move its text rather than writing a second statement
beside it.

Never write the version. It is the hash of the block, and the machinery
computes it.

Done when the block, its name and its scenarios satisfy
`flywheel/schemas/claim.md`, and the chapter that explains it includes it.
