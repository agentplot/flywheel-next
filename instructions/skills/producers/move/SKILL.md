# Producing a move

One move per signal, with a reason a stranger could weigh. Read the claim or
the intent the move points at before pointing at it.

Drop is a judgment and takes a reason. Challenge names the standing claim and
says what the signal asserts against it.

Done when every unmoved signal in the work order has exactly one move, and
`flywheel/schemas/move.md` holds.
