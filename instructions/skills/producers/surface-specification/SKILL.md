# Producing a surface specification

Write down what the exploration settled, so no one has to explore it again.
Per surface: what it shows, what it never shows, the form of each object, the
keys and the modes. Then the flows as numbered steps. Then the rulings, each
with its reason.

Cite the mockups as records in the change directory. A mockup is evidence of a
ruling, never a substitute for stating it.

Done when a construction session could build the surface from this document
alone, and `flywheel/schemas/surface-specification.md` holds.
