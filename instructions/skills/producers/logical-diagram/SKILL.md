# Producing a logical diagram

Show the components, what each is responsible for, and what crosses between
them. Label each crossing with what crosses.

Same house style as the conceptual diagram, one altitude lower: a store, a
service or a boundary may be named; a file or a function may not.

Done when the picture and the chapter say the same thing, and
`flywheel/schemas/diagram-logical.md` holds.
