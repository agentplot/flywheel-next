# persona-test, the review step

Judge the built work against the spec and against the test reports, and write
the verdict on the claims the item named.

The test reports are evidence, not a verdict. A persona finding the thing
usable does not make the claim satisfied, and a persona struggling does not by
itself make it unsatisfied; say which findings bear on which claim.

Invalid: a review that averages the personas, a verdict with no inputs named,
and a send-back that does not say what would make it pass.
