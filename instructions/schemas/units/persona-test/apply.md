# persona-test, the build step

As the default type's build step: build what the spec says, write the as-built
statements naming the claims served, commit and push nothing.

The build is finished when a person could sit down and use the thing, because
that is what happens next.

Invalid: a build that leaves a path only reachable by a test harness, and an
as-built statement naming a claim the item does not cite.
